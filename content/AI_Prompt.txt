你是一位資深前端工程師。請建立一個完整的「服飾購物網站 Clothing Store Website」，品牌名稱為：

StyleHub

網站用途：
1. HTML / CSS / JavaScript 前端教學
2. 可直接放到 GitHub Repository
3. 可直接使用 GitHub Pages 部署
4. 不需要任何後端 Server
5. 所有功能必須只靠原生 HTML、CSS、JavaScript
6. 最終只輸出一個 index.html
